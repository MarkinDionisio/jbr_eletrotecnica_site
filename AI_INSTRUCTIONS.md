# AI Guidelines for JBR Eletrotécnica Project

These rules must be strictly followed by any Artificial Intelligence assistant working on this repository.

## Git & Commits
- ALWAYS write git commit messages in English. This is a strict requirement.
- Follow the Conventional Commits pattern (e.g., feat:, fix:, chore:, docs:).

## Code & Comments
- ALL code, including variable names, function names, and comments, MUST be written in English.
- Avoid using Portuguese or other languages in the source code.

## Development & Technologies
- The project uses **Vanilla CSS** (`styles.css`). DO NOT use TailwindCSS or any other CSS framework unless explicitly requested by the user.
- The project uses pure JavaScript (Vanilla JS).
- Keep the design focused on high performance and clean code.
- Preserve responsiveness and lightweight animations.

## Communication
- Communication with the user in the chat should remain in Brazilian Portuguese (PT-BR) unless the user speaks in another language.
